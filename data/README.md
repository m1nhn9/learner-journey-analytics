# Data

This project uses the **Open University Learning Analytics Dataset (OULAD)**: anonymized data on
about 32,000 student enrollments across 22 runs of seven online courses at The Open University (UK),
including registrations, withdrawals, assessment submissions and ~10 million rows of daily
course-site activity.

**Download:** https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
Unzip the seven CSV files into this folder (`data/raw/`):

```
courses.csv  assessments.csv  vle.csv  studentInfo.csv
studentRegistration.csv  studentAssessment.csv  studentVle.csv
```

The raw files are not committed to this repository (size, and they belong to their publisher).
